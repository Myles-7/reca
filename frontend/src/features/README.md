# Feature-owned UI

Features own project, literature, data, analysis, manuscript, evidence and
approval views as their milestones are implemented. TanStack tables, PDF.js
viewer interactions and React Flow graphs remain projections over backend
authority. Feature stores may hold drafts and view state, never final approvals,
EvidenceSpan truth, versions or workflow state. M0 contains no research feature.

`research-question/` is the M2 reference structure for features with remote
state, mutations, permissions and domain status transitions. The activation
gate and the cases where this structure should not be used are defined in
`docs/development/M2_FRONTEND_FEATURE_TEMPLATE.md`.
