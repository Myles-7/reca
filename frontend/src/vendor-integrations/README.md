# Approved third-party UI integrations

Place thin wrappers and integration notes for PDF.js, TanStack Table, React Flow
or another approved UI dependency here when the owning milestone adopts them.
Each integration records package/version, source research, license, upstream
types hidden from features, fallback and acceptance evidence.

Do not place copied source or assets here without Vendor provenance. TanStack
Table is already a package dependency; PDF.js and React Flow remain planned.
Zotero projects remain design references and are not copied by this policy.
