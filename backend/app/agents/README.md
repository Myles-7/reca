# Controlled Agent layer

M1 establishes the Git-managed Prompt manifest and model-governance records.
The formal OpenAI Agents SDK runtime is planned for M8 and must run one RECA
Orchestrator over existing Tool contracts and Services.

SDK Session is not ResearchProject state and SDK Trace is not AuditLog. Selected
ARS-Codex Prompt/workflow/policy/test assets require ADR-001 review, attribution
and adaptation to RECA Project, Approval, Evidence and Tool semantics. No formal
Agent runtime is implemented in M0.
