# RECA Documentation Archive

本目录保存已经完成阶段的报告、执行记录和基线证据。

归档文档用于保留历史决策和证据，不再定义当前政策；与当前文档冲突时，以已批准正式入口、当前 ADR 和 [M1 文档基线批准记录](../reports/M1_DOCUMENTATION_BASELINE_APPROVAL.md) 为准。

## 分类

| 目录 | 内容 |
| --- | --- |
| [`document-restructure/`](./document-restructure/) | 文档拆分、压缩、迁移和一致性修复记录 |
| [`security-policy/`](./security-policy/) | 安全与开源复用政策优化阶段记录 |
| [`open-source-research/`](./open-source-research/) | 开源项目研究、对齐和阶段审查记录 |
| [`evidence/`](./evidence/) | 文档拆分与开源研究阶段生成的稳定标识和调查证据 |
| [`m0/`](./m0/) | 已完成 M0 的执行过程记录 |

根目录中的 `README_PRE_M1_LONGFORM.md` 是批准前入口文档的历史长版快照，同样不具有当前规范效力。
