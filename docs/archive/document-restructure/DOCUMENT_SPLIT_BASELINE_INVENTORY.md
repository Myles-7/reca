## 2. Extraction method

The plain-text identifier lists in document-split-baseline/ were generated in-memory from the eleven specified documents, then deduplicated and ordinal-sorted. No persistent extraction script was added. Regex classes were: requirement IDs; acceptance IDs; API paths; failure/error-name candidates; Schema-name candidates; tool names from API section 42; enum-name candidates; milestone IDs; ADR IDs; M0 issue IDs; and repository document references.

### Manual-verification boundary

* error_codes.txt and enum_values.txt are intentionally conservative machine candidate sets; some values are domain relations, environment names, or audit/job types rather than a formal enum/error code. Compare each candidate to its authority before later renaming or relocation.
* schema_names.txt captures name-shaped tokens, not an OpenAPI/Pydantic parser output.
* document_links.txt captures repository document references, not external web links or Markdown anchors. Anchor stability remains a manual review item.
* agent_tool_names.txt is scoped to the API Tool whitelist section; free-text mentions elsewhere are excluded.
